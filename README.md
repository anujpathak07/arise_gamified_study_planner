# Arise

An offline study companion for building a career in software development and AI/ML.

Arise was originally personalized around my own study goals and preparation routine. I’m sharing it with learners pursuing a similar path who want a dedicated workspace for planning, studying, and tracking progress.

This repository hosts Windows app downloads, screenshots, and release notes.

## Download & Run

Download the latest Windows ZIP from this repository’s **Releases** section.

1. Right-click the downloaded ZIP and choose **Extract All**.
2. Open the extracted **Arise** folder.
3. Double-click **Arise.exe**.

Keep all extracted files together.

**Requirements:** Windows 10/11, 64-bit x64.
No installation, Node.js, login, or internet connection is required.

## Features

- **Guided roadmap:** 959 quests across DSA, AI/ML, and Aptitude.
- **Study tracking:** A global timer, daily history, contribution calendar, and configurable days off.
- **Gamified progress:** XP, levels, ranks, and an animated particle-style brain.
- **Day planner:** Schedule study, work, meals, breaks, sleep, and personal activities.
- **Practice lab:** Track accuracy, confidence, difficulty, and weak topics.
- **Custom quests:** Add personal topics, deadlines, and resource links.
- **Reports:** Weekly/monthly charts, track totals, and CSV export.
- **Focus cycles:** Timed study blocks with uncounted breaks.
- **Notes & revision:** Learning notes and spaced reviews.
- **Backups:** Automatic local saving, manual exports, and scheduled external backups.

## Your Data

Progress is saved locally on your laptop. Use **Export backup → Restore backup** to transfer it to another device.

Scheduled external backups run while Arise is open. Keep a backup somewhere separate from your laptop.

Dates and daily totals follow your laptop’s clock and local time zone.

## Updating

Export a backup, close the old app, and extract the latest release into a new folder. On the same Windows user account, your existing progress is retained.

Use the latest version after upgrading; older versions may not preserve newer features’ data.

## Important Notes

- This is an unsigned personal build, so Windows may display a publisher warning.
- The included curriculum reflects my personal preparation plan.
- Planning activities and logging practice results do not automatically award study time or XP.
- Please report problems through this repository’s **Issues** section.
